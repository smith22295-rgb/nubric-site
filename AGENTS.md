# Nubric website

This is the public static source for nubric.dev, deployed from main through GitHub Pages.

For substantial design work, use the `nubric-web-design` skill when available and read `_ops/design/BRAND.md`. Preserve the current brand and package rules there. Small corrections should remain small.

Run `python _ops/security/verify.py` before publishing. Recalculate CSP hashes if structured data changes. Preserve the existing inquiry form and consent-based analytics protections. Do not add client records, credentials, contracts or local-suite data to this public repository.

Client Desk work notes require Adam's explicit request. Publishing a change does not authorize a note.
